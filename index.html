PSNDL by @bishalqx980

An awesome PS3/PSP/PS4 game/dlc/apps search engine. Returns download link, info, rap file, etc. (PS3 Focused)

Notes:
  • If the DOWNLOAD button doesn't works, right-click on it, copy the link, and download.
  • Missing RAP indicates that the package doesn't have/need a RAP file. (RAP is the license file for package, some game/dlc doesn't need that)
  • PS1/PS2/other .pkg files are custom/originally build for PS3 console.
